# 愛犬との「視線会話」🐕✨ AIが繋ぐ新しいペットコミュニケーション

犬が**声を発するおもちゃ**を見たことがありますか？

飼い主が「Hello」と録音して、犬がボタンを押すと「Hello」が再生される—犬と人間が言葉で「会話」する知育おもちゃです。

**それを視線トラッキングで実現しました。** 犬が画面を見つめるだけで、飼い主が事前に録音した言葉が再生される—これが我々が開発した新しい形のペットコミュニケーションです。

## 🎮 「視線会話おもちゃ」の仕組み

**従来の音声ボタンおもちゃ：**
```
犬がボタンを押す → 音声再生
```

**視線トラッキング版：**
```
犬が画面を見つめる（0.5秒） → 飼い主の声が再生される
```

ボタンを押す必要がない。**視線だけで通じ合える。**

## 🔧 実装したもの

Webカメラ1台でブラウザ上に実現：

1. **犬顔検出**（COCO-SSD）
   - 犬をリアルタイムで認識
   
2. **視線トラッキング**（Mediapipe Face Mesh）
   - 犬がどのアイテムを見てるか検出
   
3. **無限ループ対応**
   - 同じアイテムを何度でも選択可能
   - 繰り返し遊べる仕様
   
4. **カスタム音声再生**
   - 飼い主の録音音声で応答
   - スコア加算でゲーミング化

## 💡 従来のおもちゃとの違い

| 機能 | 従来のボタン型 | 視線トラッキング版 |
|------|--------|---------|
| 操作 | 押す | 見つめる |
| セットアップ | 物理おもちゃ購入 | ブラウザで無料 |
| カスタマイズ | 固定音声 | 飼い主の声を録音 |
| 行動分析 | できない | 視線データで可視化 |
| 複数ペット対応 | 難しい | 簡単 |

## 🎯 コンセプト

**「声を出すおもちゃ」は、実は：**

犬が飼い主と対話していると感じる新しい形のコミュニケーション。

従来はボタンという物理的な「媒介」が必要でした。

視線トラッキング化することで、その媒介を消し去り、もっと自然で直感的な相互作用が生まれます。

## 🛠️ 技術面での工夫

- **全ブラウザ対応** - インストール不要
- **低遅延** - TensorFlow.jsで秒単位の処理
- **軽量AI** - CPUだけで動作
- **Open Source Philosophy** - Web標準のみ使用
